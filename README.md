## Site maintenance

This is a static GitHub Pages website. Keep canonical metadata and sitemap.xml in sync when adding public pages. The duplicate /home/ alias and /showcase/ redirect are omitted from the sitemap. The unlisted student review page is marked noindex and omitted too.

QR generation happens in the browser. The QR page does not include analytics and does not upload or store entered links or count scans. Other site pages may use Cloudflare Web Analytics. The destination website can have its own tracking.

QRCode.js is vendored in assets/vendor/ under its accompanying MIT license. This license covers that dependency; it does not grant rights to Allyspan branding or publication content.
