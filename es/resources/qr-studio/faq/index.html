Preguntas frecuentes de QR Studio

Volver a QR Studio
¿Cómo creo y descargo un código QR?

Crea un QR estático para un enlace web y descárgalo como imagen PNG de 1184 × 1294 píxeles. Úsalo en diapositivas, materiales de talleres, carteles o recursos cotidianos. Funciona en tu navegador, sin cuenta ni pago.

  1. Añade tu enlace

    Pega una dirección web completa. Comprueba que sea la página que quieres que se abra.

  2. Genera tu código

    Selecciona Generar para crear el QR localmente en tu navegador. Tu enlace no se envía a Allyspan.

  3. Descarga y prueba

    Descarga el PNG, añádelo a tu material y escanea una copia de prueba antes de compartirlo o imprimirlo.

¿Qué distingue a Allyspan QR Studio?

El código contiene el enlace de destino. No pasa por redirecciones de Allyspan, contadores de escaneos ni servicios de suscripción. Allyspan no recibe ni guarda los enlaces introducidos ni las imágenes generadas. Esta página no tiene herramientas de analítica ni rastreadores publicitarios.

El navegador conserva el enlace mientras la página está abierta; la imagen descargada queda donde la guardes. Visitar esta página sigue implicando solicitudes normales de alojamiento web. El sitio que se abra al escanear puede tener sus propias herramientas de analítica o seguimiento.

¿Cómo uso códigos QR en una clase o un taller?

Ayuda a abrir una clase compartida, un recurso accesible o una página de comentarios sin escribir una dirección larga. Acompaña el QR de un enlace escrito breve y una descripción clara para que cada persona elija cómo acceder. Prueba siempre los permisos desde un dispositivo de estudiante.

Para presentaciones multilingües que puedes compartir con estudiantes, conoce Classroom Studio. Para imprimir o compartir un solo enlace, esta herramienta QR está lista sin iniciar sesión.

¿Es gratis?

Sí. Generar y descargar el QR es gratis. No necesitas un plan de pago para que el código siga funcionando.

¿Necesito una cuenta?

No. Allyspan QR Studio no requiere cuenta, correo electrónico ni registro.

¿Se guarda mi enlace?

Allyspan no lo guarda. El enlace se procesa en el navegador y no se sube a nuestros servidores. La imagen descargada contiene ese enlace: compártela solo con el público previsto.

¿El código caduca?

El QR estático no tiene caducidad integrada ni depende de una suscripción a Allyspan. Sigue apuntando a la dirección codificada. El destino debe continuar disponible; un enlace de destino temporal sí puede caducar.

¿Puedo imprimirlo?

Sí. Usa el PNG descargado, conserva el espacio blanco alrededor del código y evita estirarlo o recortarlo. Imprime una prueba al tamaño previsto y escanéala antes de producir más copias. Incluye un enlace escrito como alternativa.
