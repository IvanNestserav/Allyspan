    Classroom Studio 简介

    一堂课，更多参与方式。
    多语言课堂入门指南。

    认识 Studio

    一次创作。
    跨越语言建立联结。

    Classroom Studio 是 Allyspan 为教育工作者提供的在线演示工作区。制作可视化课程、添加多语言文字，并通过二维码或链接分享，让学生选择自己理解的可用语言跟随课程。

    教师使用 Google 登录，制作并保存演示文稿。学生无需账户即可打开共享课程，选择课程语言，并按照自己的进度浏览幻灯片。

    教师指南

    制作你的
    第一堂课。

    1. 登录。 打开 Classroom Studio 并使用 Google 登录。已保存的课程位于 My presentations（我的演示文稿）中。
    2. 选择起点。 浏览模板或创建空白演示文稿。为课程取一个日后容易识别的名称。
    3. 制作幻灯片。 编辑英文内容、添加图片并调整对象位置。每张幻灯片围绕一个重点，并为翻译预留空间。
    4. 选择语言。 在编辑器中打开 Languages（语言），选择课堂需要的语言。翻译文字，并检查准确性及课堂语境中的含义。
    5. 保存并预览。 关闭前确认状态显示 Saved（已保存）。上课前选择 Present（演示）检查课程。

    分享与演示

    邀请你的
    学生参与。

    保持 Include QR slide 0（包含二维码第 0 页） 启用，以显示欢迎页。选择 Present（演示） 会开启分享并显示课程二维码与链接。你也可以在编辑器中打开 Share & QR（分享与二维码） 。

    使用 QR options（二维码选项） 复制完整课程链接、选择二维码颜色或下载二维码图片。上课前，请用另一台设备测试二维码。

    更新课程后，同一链接仍可使用。分享开启期间，任何获得链接的人都能查看。需要停止访问时，请在分享窗口使用 Turn sharing off（关闭分享） 。

    学习者指南

    扫描。选择。
    跟随课程。

    扫描教师的二维码或打开完整课程链接。学生无需登录。

    选择可用的 Lesson language（课程语言），然后使用 Next（下一页） 和 Back（上一页） 浏览幻灯片。如有此选项，可同时显示英文与翻译。打开共享课程需要网络连接。

    课前准备

    几个实用习惯。

    检查翻译。 上课前检查重要措辞，尤其是说明与不熟悉的术语。

    谨慎分享。 只分享适合所有可能收到链接的人查看的内容。演讲者备注保留在编辑器中，不会包含在学生的共享课程内。

    准备离线副本。 下载包含已保存翻译与媒体的演示文稿。解压 ZIP 后，在现代浏览器中打开 index.html 。主屏幕快捷方式仍需网络连接。

    测试显示效果。 教师端可使用 Full screen（全屏）。手机浏览器的控件与全屏表现因设备而异。

    帮助与反馈

    一个由我们共同
    改进的平台。

    Classroom Studio 持续发展，功能与控件可能变化。如需报告问题，请登录，返回主工作区，并在侧栏选择 Report a problem（报告问题） 。

    请说明你原本想做什么、发生了什么，以及使用的设备和浏览器。可附上错误提示，但请勿提供学生姓名或私人信息。
